SchoolIQ — System Architecture & Data Flow

Multi-Tenant Isolation

Tenant partitioning implemented at the PostgreSQL schema level with row-level security (RLS) policies for cross-school data isolation. Connection pooling managed via PgBouncer.

Curriculum RAG Engine

NCERT / State Board textbooks chunked via recursive character tokenizers, embedded via Vertex AI text-embeddings, and indexed into ChromaDB. Grounded LLM generation enforces zero hallucination in exam synthesis.

Asynchronous Workflows

Redis-backed BullMQ clusters handle long-running operations: PDF exam compilation, attendance aggregate rollups, and high-volume WhatsApp notification delivery.

Telematics & Live Tracking

School transit fleet tracking using WebSockets and Google Maps Platform API with server-side point clustering and geofence breach triggers.
