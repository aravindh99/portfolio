Centralized Auth — Identity Federation & Token Lifecycle

Stateless Token Minting

Asymmetric RS256 JWT key-pair rotation. Downstream microservices verify signatures locally using in-memory cached JWKS without pinging the auth service on every request.

Instant Revocation & Redis Session Store

Opaque refresh tokens persisted in Redis with SHA-256 fingerprinting. Enables immediate global logout and revocation cascades across all client devices.

Hierarchical RBAC

Bitmask-based and scoped role-permission trees cached in Redis hashes, evaluated in sub-millisecond middleware before routing to core ERP and CRM service handlers.

Rate Limiting & Threat Mitigation

Sliding window rate limiters implemented via Redis Lua scripts against brute-force credential stuffing and enumeration attacks.
